# 🍊 OrangeVerse · 橘域

> **“一个小橘的 AI 全栈与 Vibe Coding 个人宇宙。”**

基于 Three.js、Vite 与沉浸式 3D 岛屿构建的开发者个人空间。收录 GitHub 开源仓库、《AI-Daily-Learning》学习书本、掘金技术专栏与在线简历。

## 🌟 核心特性

- 🏝️ **3D 沉浸式漫游主岛**：支持森林、沙洲、浅海三大主题实时切换，角色自动寻路、绕障避障、WASD / 触控漫游与小地图雷达。
- 🗂️ **宇宙档案**：从 `archive.html` 搜索简历、仓库、学习和写作，或直达浅海漫游。
- 📄 **在线简历**：全屏查看开发技能、代表项目与学习成果，支持导出 / 打印 PDF。
- 📚 **《AI-Daily-Learning》学习书本与掘金专栏**：聚合 AI Agent 架构、MCP 协议、RAG 私域校准、RN 动效基建等多篇高赞硬核技术长文。
- 🐙 **GitHub 开源项目展厅**：精选 `parent_kid_edu`（童心智伴）、`react-playground`（在线编译沙箱）、`chatbox-demo` 等开源代表作。
- 🧪 **Vibe Coding 实验室**：面向未来的可插拔组件插槽设计，预留 **Motion Sites** 与 **React Bits Pro** 动效组件集成位。

## 🛠️ 本地运行与开发

```bash
# 1. 安装依赖
npm ci

# 2. 自动化测试
npm test

# 3. 启动本地开发服务 (默认端口 5173)
npm run dev

# 4. 构建生产产物
npm run build
```
